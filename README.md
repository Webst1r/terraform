# Terraform: Up & Running — Interactive Summary

An interactive chapter-by-chapter summary of *Terraform: Up & Running (3rd Edition)* by Yevgeniy Brikman.

Built with React + Vite. Deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

Or connect your GitHub repo to Vercel and it auto-deploys on every push.
